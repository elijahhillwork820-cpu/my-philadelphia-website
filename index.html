Responsive Design Reflection

  1. The most significant layout issue I needed to consider was making sure the website's content, navigation, and images fit different screen sizes without causing horizontal scrolling.
  2. I used CSS properties and techniques such as box-sizing, max-width, width, margin, padding, and height: auto. I also used media queries to adjust the layout for smaller screens.
  3. On wider screens, the content has more room to spread out while remaining centered. On narrower screens, the spacing is reduced and navigation links can wrap or stack to make the page easier to use.
  4. Testing at desktop, tablet, and mobile viewport widths helped me understand why responsive design matters. I learned that a page must remain readable and usable instead of simply shrinking to fit the screen.
  5. My next improvement would be to test additional screen sizes and improve the navigation further if needed. I would also continue checking image proportions, text wrapping, spacing, and accessibility.
